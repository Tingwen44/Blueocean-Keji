# 柯基 1 页纸 · 用户使用说明书

> 基于 BlueOcean Asset 卖方主观分析框架 · v1.0
> 适用部署: https://web-production-79c8f.up.railway.app/

---

## 这是什么

1 个 ticker 输入 → 系统跑 8 步分析 → 输出 1 页纸 (HTML/PDF)

适合场景：
  - 单只个股深度研究 (15-30 分钟出结论)
  - 建仓前最后核对 (8 个维度 + 风险 + 止损)
  - 投委会讨论的 1 页支撑材料
  - 写进投资笔记 / 雪球 / 公众号

**不适合**：实时盯盘、批量扫描 (那是量化工具干的活)

## 5 分钟上手

### 第 1 步：打开前端

浏览器访问部署 URL → 看到顶部输入框 (默认空)

### 第 2 步：(可选) 配置 LLM

点右上 **⚙️ 设置** → 选 Provider (OpenAI / Gemini) → 填 API key → **测试连接** → 保存

- 不配也能用, 系统走"规则化降级" (产业链定位用预设规则, 催化列表为空)
- 配了之后 Step ③ ④ 会有 LLM 给的深度分析, 信息密度高 3-5 倍
- key 只存你浏览器, 不上服务器, 换电脑要重新配

### 第 3 步：输入 ticker + 分析

输入框打 `COHR` (或 NVDA / MU / 0700.HK) → 回车 → 等 5-15 秒

左侧"进度"栏会显示 8 步状态, 主区域依次展开各步内容

### 第 4 步：看自动结果 (Step 1-5, 7)

主区域从上到下滚动, 看:
  - **① 顶部摘要**: 当前价 / 目标价 / 综合分 / 信号 / 1 句结论
  - **② 4 维基本面**: 4 个信号灯 (绿=bullish, 灰=neutral, 红=bearish) + 详情
  - **③ 产业链定位**: 瓶颈 vs 工具 vs 周期, 涨价权, 量价趋势
  - **④ 催化时点**: 未来 6 个月的关键事件 (财报/订单/政策)
  - **⑤ 日历+事件**: 距中期选举/鲍威尔卸任多少天, 财报季位置
  - **⑦ 见顶信号**: 7 个 trigger 哪些触发了 (0/7 触发表强势, 5/7 表危险)

### 第 5 步：填手动部分 (Step 6 + 8)

**这是关键, 别跳过** (后面详细讲怎么填)

### 第 6 步：导出 / 保存

- **导出 HTML**: 浏览器新标签打开, 可直接打印
- **导出 PDF**: 下载, 适合发邮件 / 微信 / 团队分享
- **保存到历史**: 进 SQLite, 之后 📚 历史 抽屉可回看
- (默认分析自动存历史, 不需要手动点)

## ⏸ 手动部分 (Step 6 + 8) 详解

为什么这两步要手动? 因为它们是**主观判断**, AI 没有你的产业认知 / 行业经验 / 资金面直觉。系统留给你, 是因为这两步的答案会**显著影响最终信号**。

---

### ⑥ 轮动定位 (4 个字段)

这一步回答: **"这只股票在当前主线轮动中, 处于什么位置?"**

#### 6.1 轮动位置 (4 选 1 下拉)

| 选项 | 含义 | 典型场景 |
|---|---|---|
| **leading** 领涨 | 主线刚启动, 这只票是龙头 | 2024 H1 NVDA 在 AI 主线 |
| **mid** 中段 | 主线推进中, 主流标的 | 2024 H2 MU/AVGO 接棒 |
| **late** 末段 | 主线快结束, 高位震荡 | 2025 H1 部分光通信股 |
| **catchup** 补涨 | 主线扩散到二三线标的 | 主力涨完后小票跟涨 |

**怎么选**: 看你对该股的"市场认知阶段"判断, 不需要精确, 选个大概就行

#### 6.2 轮动链 (填空)

例: `算力主线 → 高低切补涨`

描述: 这只票所属的板块**当前正在轮动链的什么位置**

**怎么填**:
  - 答得出具体链 (如"电力→核电→燃料电池") 写具体
  - 答不出就写"主线 X, 中段/末段"

#### 6.3 资金流 (填空)

例: `BTC → ETH → SOL` 或 `大盘 → 中盘 → 小盘`

描述: **资金正在从哪儿流向哪儿**

**怎么填**:
  - 答得出写具体方向
  - 答不出写"无明显轮动"或留空

#### 6.4 相对表现 (填空)

例: `1m +18%, 跑赢纳指 12pct` 或 `3m -8%, 跑输板块 5pct`

描述: **这只票相对市场的强弱**

**怎么填**:
  - 用 1m / 3m 数字 + 相对基准 (纳指/标普/板块)
  - 没数据就写"无明显差异"

---

### ⑧ 风险定价 (4 个字段)

这一步回答: **"什么情况下我应该砍仓? 砍多少?"**

#### 8.1 风险列表 (可加多条)

每条风险有 3 个字段:

| 字段 | 含义 | 填什么 |
|---|---|---|
| **严重程度** | high / medium / low | high = 致命伤 (破产/监管), low = 小扰动 |
| **风险描述** | 一句话说清楚是什么风险 | 例: "商誉 77 亿 / 总资产 51%" |
| **触发信号** | 出现什么信号就该跑 | 例: "跌破 200d MA" / "Q2 财报 EPS 转负" |

**填几条**:
  - 至少 1 条 (默认给你预填 1 条占位)
  - 3-5 条最常见 (系统性风险 / 公司具体风险 / 行业风险 / 估值风险)
  - 不超过 10 条 (UI 限制)

**举例** (NVDA):
  - [HIGH] 估值风险 / 触发: 远期 PE 跌破 25x
  - [HIGH] 客户集中度 / 触发: Top 3 客户份额 < 50%
  - [MED] 中国出口管制 / 触发: 美国对华 H20 进一步限制
  - [MED] 周期下行 / 触发: 半导体周期 SA < 90

#### 8.2 止损价 (数字)

例: `95.50`

含义: **股价跌破这个数, 无条件砍仓**

**怎么定**:
  - 紧止损: 现价 × 0.85 (15% 止损) — 短线
  - 中止损: 现价 × 0.75 (25% 止损) — 中线
  - 宽止损: 200d MA 或 52w low — 长线

#### 8.3 止损百分比 (数字)

例: `-20`

含义: 从成本价算起, 跌多少 % 砍仓

**怎么定**:
  - 跟止损价对应, 填一个就行
  - 两个都填, 系统按**更紧的那个**生效

## 信号解读

**综合分** (1-10):
  - 0-3: **bearish** (看空, 红色)
  - 4-5: **neutral** (中性, 灰色)
  - 6-7: **bullish** (看好, 绿色)
  - 8-10: **extreme bullish** (强看好, 深绿, 警惕过热)

**置信度** (0-100%):
  - 50% 以下: 系统不确定, 多看少动
  - 50-75%: 可参考
  - 75% 以上: 较强信号, 但仍需结合你的研究

**单信号 1 句结论**:
  > "BULLISH 盈利, BULLISH 增长, NEUTRAL 估值; 情绪 extreme_greed; 综合分 7.5/10 → bullish"
  - 拆开读: 4 维基本面信号 + 市场情绪 + 综合分 + 最终信号

## 常见场景 (用法模板)

### 场景 A: 建仓前最后核对 (15 分钟)

1. 输入 ticker
2. 看 ①-⑤-⑦ 自动结果 (5-15 秒)
3. 填 ⑥ ⑧ 手动 (5 分钟)
4. 看综合分 + 1 句结论 (30 秒)
5. 导出 PDF 存档
6. 决策: 建仓 / 放弃 / 等回调

### 场景 B: 已持仓复盘 (10 分钟)

1. 📚 历史抽屉找之前分析
2. 点回看, 对比当前价 vs 当时价格
3. 重新跑一次, 看 ⑦ 见顶信号是否新触发
4. 决定: 加仓 / 持有 / 减仓

### 场景 C: 写研报 / 公众号 (30 分钟)

1. 跑 1-2 只对比 (手动对比, 没有多 ticker 功能)
2. 导出 HTML
3. 在 HTML 基础上修修改改, 截图 / 复制
4. 加上你自己的产业逻辑

### 场景 D: 团队投委会讨论 (5 分钟/只)

1. 跑 N 只 (每次一只, 5-15 秒)
2. 导出 PDF
3. 会上展示, 同事质疑时直接打开 ⑦ 见顶信号 + ⑧ 风险定价

## Q&A

**Q: 不配 LLM 也能用吗?**
A: 能。Step ③ 产业链定位走规则化降级 (按 industry 关键词分类), Step ④ 催化列表为空。其余 6 步都正常。

**Q: 配了 LLM 但 key 错了会怎样?**
A: 后端自动降级, 不会 500。UI 顶栏状态点会变灰, 提示"key 失效"。

**Q: 历史记录会丢吗?**
A: 取决于部署。如果 Railway 没挂持久卷 (Volume), 重启会丢。建议加 `/app/data` 卷 1GB (详见 RAILWAY.md)。

**Q: 能跑港股 / A 股吗?**
A: 能。yfinance 支持港股 (0700.HK), A 股需要换数据源 (AKShare)。目前没接 A 股, M1+ 待做。

**Q: 能批量跑 27 只吗?**
A: 不能, 一次 1 只。但你可以在外部脚本调 API:
```bash
for t in NVDA COHR MU AVGO; do
  curl -X POST https://your-url/api/one-pager/$t \
    -H "Content-Type: application/json" -d '{"use_llm":true,"save_to_db":true}'
done
```

**Q: 跑出来跟彭博/同花顺不一致?**
A: 数据源是 yfinance (Yahoo), 跟彭博/Wind 通常差异 <0.5%。如果差异大, 大概率是 timing (盘前盘后) 或公司行动 (拆股) 没同步。
